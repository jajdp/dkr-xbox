# Esta carpeta está vacía a propósito

*(English: [README.md](README.md))*

Los nueve mosaicos del paquete **no** se distribuyen aquí: los del port real están hechos con la
carátula de *Diddy Kong Racing*, que no es nuestra para publicarla.

Pon los tuyos — las medidas, los nombres y las cuatro cosas que es fácil equivocar están en
[`../../docs/ASSETS.es.md`](../../docs/ASSETS.es.md)
([in English](../../docs/ASSETS.md)). `tools/make_tiles.py` convierte cuatro imágenes en los nueve
que el manifiesto necesita, y `tools/package_uwp.py` se detiene con un mensaje claro si falta
alguno.

Este leeme y su versión en inglés son los únicos archivos que el `.gitignore` deja pasar aquí, para
que la carpeta sobreviva a un clon recién hecho.
